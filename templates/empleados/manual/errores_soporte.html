Manual de Usuario - Sistema GK

Errores comunes y contacto de soporte

Introducción

Esta sección del manual te ayudará a resolver los problemas más comunes que puedes encontrar al usar el Sistema GK. Si después de seguir estas soluciones el problema persiste, encontrarás información de contacto para obtener ayuda adicional.

Errores Comunes y Soluciones

No puedo iniciar sesión

Posibles causas y soluciones:

  • Usuario o contraseña incorrectos: Verifica que estés escribiendo correctamente tu usuario y contraseña. Recuerda que ambos campos distinguen entre mayúsculas y minúsculas.
  • Cuenta desactivada: Si tu cuenta ha sido desactivada, contacta al área de Sistemas para reactivarla.
  • Problemas de conexión: Verifica tu conexión a internet y que puedas acceder al sitio web del sistema.

Nota: El sistema no cuenta con función de "Olvidé mi contraseña". Si no recuerdas tu contraseña, deberás contactar al área de Sistemas.

No tengo acceso a una funcionalidad

Posibles causas y soluciones:

  • Permisos insuficientes: Algunas funcionalidades están restringidas según tu rol en el sistema. Verifica que tu perfil tenga los permisos necesarios.
  • Perfil no configurado correctamente: Si crees que deberías tener acceso, contacta al área de Recursos Humanos para verificar tu perfil.
  • Navegación incorrecta: Asegúrate de estar en la sección correcta del sistema según tu rol.

No puedo solicitar vacaciones

Posibles causas y soluciones:

  • Días disponibles agotados: Verifica en tu perfil cuántos días de vacaciones tienes disponibles. Si no tienes días disponibles, no podrás crear una solicitud.
  • Fecha inválida: Asegúrate de seleccionar fechas válidas y que no estén en el pasado.
  • Rango de fechas incorrecto: Verifica que la fecha de inicio sea anterior a la fecha de fin.
  • Días insuficientes: El sistema calcula automáticamente los días solicitados. Asegúrate de tener suficientes días disponibles.

Error al guardar información

Posibles causas y soluciones:

  • Campos obligatorios vacíos: Revisa que todos los campos marcados con asterisco (*) estén completos.
  • Formato de datos incorrecto: Verifica que los datos ingresados tengan el formato correcto (fechas, números, etc.).
  • Datos duplicados: Algunos campos requieren valores únicos (como números de serie, códigos de inventario). Verifica que no estés intentando usar un valor que ya existe.
  • Problema de conexión: Si el problema persiste, puede ser un problema temporal de conexión. Intenta nuevamente en unos momentos.

La página no carga o se ve mal

Posibles causas y soluciones:

  • Problema de caché del navegador: Intenta limpiar la caché de tu navegador o usar el modo incógnito.
  • Navegador desactualizado: Asegúrate de estar usando una versión actualizada de tu navegador (Chrome, Firefox, Edge, Safari).
  • Extensiones del navegador: Algunas extensiones pueden interferir con el funcionamiento del sitio. Intenta desactivarlas temporalmente.
  • JavaScript deshabilitado: El sistema requiere JavaScript para funcionar correctamente. Asegúrate de tenerlo habilitado.

No puedo descargar reportes o PDFs

Posibles causas y soluciones:

  • Bloqueador de ventanas emergentes: Algunos navegadores bloquean las descargas. Verifica la configuración de tu navegador y permite ventanas emergentes para este sitio.
  • Permisos de descarga: Asegúrate de que tu navegador tenga permisos para descargar archivos.
  • Espacio en disco: Verifica que tengas suficiente espacio en tu dispositivo para guardar el archivo.
  • Problema temporal: Si el problema persiste, intenta nuevamente después de unos minutos.

No encuentro información o funcionalidad

Posibles causas y soluciones:

  • Navegación incorrecta: Revisa el menú principal y asegúrate de estar en la sección correcta según tu rol.
  • Filtros aplicados: Si estás en una lista o tabla, verifica que no tengas filtros aplicados que oculten la información que buscas.
  • Permisos insuficientes: Algunas funcionalidades pueden no estar disponibles para tu perfil. Verifica tus permisos.

Consejos Generales

Mantén tu navegador actualizado: Usar la versión más reciente de tu navegador ayuda a evitar problemas de compatibilidad y mejora la seguridad.

Guarda tu trabajo frecuentemente: Si estás completando formularios largos, guarda la información periódicamente para evitar perder datos.

Verifica la información antes de enviar: Revisa todos los campos antes de guardar para evitar errores que requieran correcciones posteriores.

Importante: Si experimentas problemas persistentes que no se resuelven con estas soluciones, no intentes solucionarlos por tu cuenta. Contacta al área de Sistemas para obtener ayuda profesional.

Contacto y Soporte

Si después de revisar esta guía sigues teniendo problemas, o si necesitas ayuda con alguna funcionalidad del sistema, puedes contactar al área de Sistemas a través de los siguientes medios:

Correo Electrónico

sistemas@grupokeila.com

Envía un correo detallando el problema que estás experimentando. Incluye capturas de pantalla si es posible, y describe los pasos que seguiste antes de que ocurriera el error.

Wave (Comunicación Interna)

Contacta al área de Sistemas a través de Wave

Puedes comunicarte con el área de Sistemas mediante la plataforma Wave de la empresa. Busca al personal del área de Sistemas en el directorio de contactos.

Nota: La extensión de Wave puede cambiar según la asignación del personal. Consulta el directorio interno de la empresa para obtener la información de contacto actualizada.

Información a Incluir al Solicitar Soporte

Para agilizar la resolución de tu problema, incluye la siguiente información:

  • Descripción detallada del problema
  • Pasos para reproducir el error
  • Capturas de pantalla (si aplica)
  • Mensajes de error exactos que aparecen
  • Navegador y versión que estás usando
  • Tu usuario en el sistema
  • Fecha y hora aproximada en que ocurrió el problema

Conclusión

Esperamos que esta guía te haya sido útil. El Sistema GK está diseñado para facilitar la gestión de recursos humanos y equipos en Grupo Keila. Si tienes sugerencias para mejorar el sistema o esta documentación, no dudes en compartirlas con el área de Sistemas.

Gracias por usar el Sistema GK. Estamos comprometidos en brindarte la mejor experiencia posible.
