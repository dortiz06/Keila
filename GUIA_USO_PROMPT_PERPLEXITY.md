# Guía de Uso: Cómo Usar el Prompt con Perplexity

## Pasos para Generar el Manual Completo

---

## Paso 1: Preparar los Archivos

Asegúrate de tener estos archivos listos:

1. ✅ `PROMPT_PERPLEXITY_MANUAL_COMPLETO.md` (el prompt maestro)
2. ✅ `PROMPT_EXPERTO_MANUALES_IA.md` (prompt de estructura y estilo)
3. ✅ `PROMPT_ORGANIZACION_POR_USUARIOS.md` (prompt de organización por usuarios)
4. ✅ `IDENTIDAD_VISUAL_GRUPO_KEILA.md` (colores, tipografías, estilo)

---

## Paso 2: Abrir Perplexity

1. Ve a [perplexity.ai](https://www.perplexity.ai)
2. Inicia sesión o crea una cuenta
3. Selecciona el modelo más reciente (Claude Sonnet, GPT-4, etc.)

---

## Paso 3: Enviar el Prompt Maestro

**Primera interacción con Perplexity:**

Copia y pega el contenido completo de `PROMPT_PERPLEXITY_MANUAL_COMPLETO.md` en el chat de Perplexity.

**Mensaje inicial:**
```
Hola, necesito que generes un Manual de Usuario completo para el Sistema GK de Grupo Keila. 

[Pega aquí todo el contenido de PROMPT_PERPLEXITY_MANUAL_COMPLETO.md]
```

---

## Paso 4: Enviar los Prompts Especializados

Una vez que Perplexity confirme que entendió el prompt maestro, envía los 3 prompts especializados **uno por uno**:

### 4.1. Primer Prompt Especializado

**Mensaje:**
```
Aquí está el primer prompt especializado que debes seguir:

[Pega aquí todo el contenido de PROMPT_EXPERTO_MANUALES_IA.md]
```

### 4.2. Segundo Prompt Especializado

**Mensaje:**
```
Aquí está el segundo prompt especializado que debes seguir:

[Pega aquí todo el contenido de PROMPT_ORGANIZACION_POR_USUARIOS.md]
```

### 4.3. Tercer Prompt Especializado

**Mensaje:**
```
Aquí está el tercer prompt especializado que debes seguir:

[Pega aquí todo el contenido de IDENTIDAD_VISUAL_GRUPO_KEILA.md]
```

---

## Paso 5: Confirmar y Solicitar el Manual

**Mensaje final:**
```
Perfecto. Ahora que tienes todos los prompts y las instrucciones:

1. Aplica TODAS las reglas de los 3 prompts especializados
2. Genera el manual completo siguiendo la estructura requerida
3. Incluye TODAS las secciones mencionadas
4. Agrega espacios para capturas de pantalla con descripciones detalladas
5. Usa el estilo corporativo de Grupo Keila
6. Organiza por tipos de usuario
7. Mantén el lenguaje simple y claro

Por favor, genera el manual completo en formato Markdown.
```

---

## Alternativa: Envío en una Sola Interacción

## Si Perplexity Pregunta

### Pregunta: "¿Tienes capturas de pantalla?"
**Respuesta:**
```
No, no tengo las capturas de pantalla aún. Por favor, deja espacios claramente marcados con el formato [CAPTURA DE PANTALLA: descripción detallada] para cada imagen que debe incluirse. Las descripciones deben ser muy específicas sobre qué debe mostrar cada captura.
```

### Pregunta: "¿Qué información específica del sistema necesitas?"
**Respuesta:**
```
Usa la información general que te proporcioné en los prompts. Si necesitas detalles específicos que no están en los prompts, puedes inferirlos de manera lógica basándote en sistemas similares de gestión de recursos humanos. Lo importante es que el manual sea completo, bien estructurado y profesional.
```

### Pregunta: "¿Prefieres un formato específico?"
**Respuesta:**
```
Sí, formato Markdown (.md) con encabezados claros (#, ##, ###), listas numeradas para pasos, listas con viñetas para opciones, negritas para énfasis, y cajas de información usando > para tips y advertencias.
```

---

## Después de Generar el Manual

Una vez que Perplexity genere el manual:

1. **Revisa** que tenga todas las secciones
2. **Verifica** que los espacios para capturas estén bien marcados
3. **Comprueba** que el lenguaje sea claro y consistente
4. **Ajusta** si es necesario (puedes pedirle a Perplexity que modifique secciones específicas)

---

## Consejos Adicionales

### Para Mejores Resultados:

1. **Sé específico**: Si Perplexity no sigue alguna regla, recuérdasela
2. **Pide revisiones**: Puedes pedirle que revise secciones específicas
3. **Itera**: Si algo no te gusta, pide ajustes
4. **Usa el contexto**: Perplexity puede mantener el contexto de la conversación

### Ejemplo de Ajuste:

Si el manual generado no tiene suficiente detalle en las capturas:

```
El manual está bien, pero necesito que las descripciones de las capturas de pantalla sean más detalladas. Por favor, expande cada [CAPTURA DE PANTALLA: ...] para incluir más información específica sobre colores, elementos visibles, estados, y acciones resaltadas.
```
